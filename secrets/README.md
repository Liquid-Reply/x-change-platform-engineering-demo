# Secrets Directory

This directory contains local secrets for the IDP platform.
**These files are gitignored and must be created manually.**

## Required Files

### `github-token`
GitHub Personal Access Token with `repo` scope (or `contents:write` + `pull_requests:write`).

```bash
echo "ghp_your_token_here" > secrets/github-token
```

## Optional Files

### `dt-credentials.env`
Dynatrace credentials for observability integration.

```bash
cat > secrets/dt-credentials.env << 'EOF'
DT_ENV_NAME=abc12345
DT_ENV=live
DT_RW_API_TOKEN=dt0c01.xxx
DT_OAUTH_CLIENT_ID=dt0s02.xxx
DT_OAUTH_CLIENT_SECRET=xxx
DT_OAUTH_ACCOUNT_URN=urn:dtaccount:xxx
EOF
```

### `backstage.env`
Additional Backstage environment variables (auto-generated by bootstrap.sh).

## Security Notes

- Never commit secrets to git
- Use fine-grained PATs with minimal permissions
- Rotate tokens regularly
- For production, use a secrets manager (Vault, AWS Secrets Manager, etc.)
